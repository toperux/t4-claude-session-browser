# docs

- `backlog.md` — open items no plan schedules, with the trigger that would reopen each.
- `<category>/` — plans in progress. None at the moment.
- `archive/<category>/` — finished plans, kept for the decisions they record. Each opens
  with a dated status block: what landed, in which commits, and what is still open.

Categories so far: `ci` (workflow alignment rounds), `reviews` (codebase review and its
follow-up).
